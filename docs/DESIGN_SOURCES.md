# Turnout design sources

- **Dongle (logo only):** designed by Yanghee Ryu; [Google Fonts specimen](https://fonts.google.com/specimen/Dongle) and [official font repository](https://github.com/google/fonts/tree/main/ofl/dongle). The bold (700) Latin WOFF2 subset is bundled in `public/fonts/dongle`, obtained from Google's font stylesheet. The SIL Open Font License is included at [../public/fonts/dongle/OFL.txt](../public/fonts/dongle/OFL.txt).
- **Poppins (application UI):** [Google Fonts specimen](https://fonts.google.com/specimen/Poppins) and [official font repository](https://github.com/google/fonts/tree/main/ofl/poppins). Regular (400), medium (500), semibold (600), and bold (700) Latin WOFF2 subsets are bundled in `public/fonts/poppins`. Poppins is used for headings, navigation, body text, forms, and numbers; Dongle remains exclusive to the logo. [SIL Open Font License](../public/fonts/poppins/OFL.txt). Unsupported glyphs fall back to the system sans serif. Neither font requires a Google Fonts request at runtime.
- **Top navigation:** adapted from the expandable three-card pattern of [React Bits Card Nav](https://www.reactbits.dev/components/card-nav), [TypeScript/CSS source](https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/Components/CardNav). Turnout uses CSS transitions, its existing Lucide icons, Next.js links, role-aware destinations, and keyboard/mobile behavior instead of the reference's GSAP animation. [React Bits license](REACT_BITS_LICENSE.md).
- **Colors:** primary `#CE93D8`, secondary `#FFF59D`, chosen by the team. Dark plum is used for text on these light colors; darker purple supports links and focus indicators.
- **Artwork:** the hero's circles, people icon, and labels are composed in HTML/CSS using the existing Lucide library. Existing event photographs retain their attribution in the README.
